## Evidence Classification

Use these distinctions consistently:

- **No evidence** — the record does not support an assessment.
- **Negative task evidence** — the response demonstrates poor performance on the task asked.
- **Irrelevant response** — the response does not address the task.
- **Platform or capture fault** — the exchange is compromised by the interface or recording method.
- **Interviewer deviation** — the interviewer departed from the approved procedure.
- **Positive evidence** — the response directly demonstrates the assessed behaviour.
