## Changelog Principles

- Do not rewrite old entries merely because later knowledge changes.
- Add a correction or superseding entry.
- Link to the relevant experiment, source record, decision, or release whenever possible.
- Distinguish changed evidence from a changed interpretation.
- Never describe unverified work as completed.
