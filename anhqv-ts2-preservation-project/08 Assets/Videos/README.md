# Video Evidence

This directory documents audiovisual evidence and publication artefacts.

Raw recordings are not committed to the initial GitHub repository. Three clean EXP001 viewing copies are already available on YouTube and are documented in the inventory.

## Why Raw Video Is Withheld

The current recordings are:

- large;
- working evidence rather than finished publications;
- partly redundant;
- affected by incidental personal audio and incomplete narration;
- in need of rights, privacy, and evidential review.

The originals remain in lcd97's local custody.

## Evidence Layers

### Raw Evidence

Untouched source recording with original filename, checksum, and custody record.

### Working Edit

Non-final project file used for cutting, captions, audio processing, and review.

### Public Demonstration

Rights-reviewed export designed to communicate an observation efficiently.

### Edit Log

A durable record linking the public demonstration to its raw source and describing meaningful transformations.

## Rule

A public edit never replaces the raw evidence.
