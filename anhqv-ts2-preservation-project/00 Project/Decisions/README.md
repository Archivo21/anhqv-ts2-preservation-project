# Decisions

This directory records decisions that affect project architecture, policy, public use, or interpretation.

A decision record explains:

- the issue;
- options or concerns considered;
- the decision;
- the reason;
- affected documents;
- later review triggers.

Decision records preserve why the project changed. Active policy remains in the relevant canonical documents.
