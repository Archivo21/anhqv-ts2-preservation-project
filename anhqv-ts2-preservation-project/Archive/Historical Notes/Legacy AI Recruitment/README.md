# Legacy AI Recruitment Documents

The documents in this directory preserve the project's earliest AI-specific recruitment approach.

They were superseded when the project adopted an implementation-independent framework based on:

- contributor identity;
- mission role;
- permission level;
- capability and evidence handling.

They remain available as historical evidence of how the governance model developed.

Use the active [Recruitment Pack](../../../00%20Project/Recruitment%20Pack/) for current policy.
