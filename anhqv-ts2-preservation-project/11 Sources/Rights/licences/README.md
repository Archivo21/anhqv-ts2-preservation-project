# Licence Records

This directory records licences that apply to project sources or archived material.

Each record should identify:

- the licence name and version;
- the rights holder or licensor;
- the material to which it applies;
- the source of the licence text;
- attribution requirements;
- restrictions or conditions;
- whether embedded third-party material is excluded;
- the project's interpretation and reviewer;
- any later licence change.

Do not copy a generic licence into this directory and assume it applies. The record must connect the licence to specific material and provenance.
