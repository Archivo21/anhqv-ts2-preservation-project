# Rights Records

This directory documents the legal and ethical basis on which the project may use, preserve, quote, reproduce, modify, or distribute source material.

It contains records, not necessarily the original evidence itself.

Where correspondence or signed material cannot be published, the record should identify its secure location and preserve enough metadata to verify that it exists.

Subdirectories:

- `permissions/` — explicit grants, refusals, withdrawals, and pending requests.
- `licences/` — licence texts, interpretations, and applicability notes.

A source record must not describe material as freely reusable merely because it is publicly accessible.

When rights are uncertain, record the uncertainty and limit project use accordingly.
