# Web Source Records

This directory contains records for websites, individual web publications, online databases, forums, and other network-accessed sources.

A web source record should include:

- canonical URL;
- site or publication title;
- operator, author, or publisher;
- first examination and latest check dates;
- relevant sections;
- reliability and verification notes;
- legal or licensing information;
- known archive captures;
- link-rot or preservation risk;
- whether automated capture or public mirroring is authorised.

A website may contain several different content types. Record those distinctions rather than assigning one reliability judgement to the entire domain.

The archived bytes of a website do not belong here. Store authorised captures in the designated archive location and link them from the source and capture records.
