# Source Templates

These templates provide consistent starting points without forcing identical treatment for every source.

Available templates:

- `source-record-template.md` — identifies and evaluates a source.
- `permission-record-template.md` — records explicit permission, refusal, withdrawal, or an unresolved request.
- `archive-capture-template.md` — documents a specific preservation capture.

Instructions inside HTML comments may be removed after completing a record.

Templates should evolve when real use reveals missing fields. Avoid adding fields merely because they might theoretically be useful.
